# 📹 Camera Monitor

Bilgisayara bağlı kameraları algılayan ve seçilen kameranın canlı görüntüsünü web arayüzünde gösteren basit bir kamera izleme uygulamasıdır.

## 🚀 Özellikler

- 📷 Bağlı kameraları otomatik olarak algılar
- 🟢 Kamera bağlantı durumunu gösterir
- 🎥 Seçilen kameranın canlı görüntüsünü gösterir
- 🔄 Kamera takılıp çıkarıldığında listeyi otomatik günceller
- 🖥️ Modern ve responsive arayüz
- 🔐 Tarayıcı kamera izinlerini kullanır

## 🛠️ Kullanılan Teknolojiler

- HTML
- CSS
- JavaScript
- MediaDevices API
- `getUserMedia()`
- `enumerateDevices()`
- `devicechange`
